# Frontend Assets

This folder contains static assets for the Laplin Atena Corrector frontend:

## Structure:
- **images/**: Logo, icons, and other images
- **fonts/**: Custom fonts (if needed)
- **icons/**: SVG icons and favicons

## Usage:
- Place logos and branding images in `images/`
- Add custom fonts in `fonts/` and reference them in CSS
- Store favicons and app icons in `icons/`

## Recommended Images:
- logo.png (main application logo)
- favicon.ico (browser tab icon)
- og-image.png (social media preview image)
- hero-background.jpg (hero section background)

## Optimization:
- Compress images for web use
- Use SVG for icons when possible
- Optimize file sizes for better performance
